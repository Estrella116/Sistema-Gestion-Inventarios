# Sistema de Gestión de Inventarios

## Descripción
Este proyecto consiste en un sistema de gestión de inventarios desarrollado en Java.

## Tipos de productos
- Electrónicos
- Alimentos
- Ropa

## Conceptos utilizados
- Herencia
- Polimorfismo
- Clases abstractas
- Interfaces

## Funcionamiento
El programa permite registrar productos, mostrar sus características y calcular el valor total del inventario.
